**Bank Account Management System**
A Python-based Bank Account Management System developed using Tkinter.

**Features**
-Create Account
-Login and Logout
-Deposit Money
-Withdraw Money
-Money Transfer
-Check Balance
-Transaction History
-JSON Data Storage

**Technologies Used**
-Python
-Tkinter
-JSON
-Object-Oriented Programming

**How to Run**
Run the Python file using:
python "Bank account using Tkinder.py"

**Purpose**
This project was developed for learning Python programming and GUI application development.
